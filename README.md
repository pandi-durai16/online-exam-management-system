# Online Exam Management System

## Overview
The Online Exam Management System is a web-based application developed to conduct online examinations efficiently. It provides separate interfaces for Admin and Students.

## Features
- Admin Login
- Student Login
- Question Management
- Online Timed Exams
- Automatic Result Generation
- Leaderboard System
- Secure Authentication

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- MySQL

## Modules
### Admin
- Manage Students
- Add Questions
- View Results

### Student
- Attend Exams
- View Scores
- Check Leaderboard

## How to Run
1. Install Python
2. Configure MySQL Database
3. Import `database.sql`
4. Run:

```bash id="1s1jz"
python app.py
```

5. Open browser:
```text id="ql02x"
http://localhost:5000
```
